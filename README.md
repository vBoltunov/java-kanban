# Java Kanban - HTTP Task Server (Java без фреймворков)

## 📋 О проекте
Реализация бэкенда для Kanban-трекера задач на чистом Java с использованием:
- `com.sun.net.httpserver.HttpServer` (встроенный HTTP сервер JDK)
- Без Spring, Spark или других фреймворков
- Собственная реализация роутинга и обработчиков

## 🎯 Цель проекта
- Понять основы HTTP протокола и работы веб-серверов
- Реализовать REST API "с нуля"
- Освоить многопоточную обработку запросов
- Создать чистую архитектуру без зависимостей от фреймворков

## 🏗️ Архитектурные особенности
- **Кастомные HttpHandlers** для каждого эндпоинта
- **Кастомные адаптеры* для сериализации данных
- **Собственный TaskManager** с историей и приоритизацией
- **RESTful API** design

## 🛠️ Технологии
- **Java 11+** (Corretto 21)
- **JDK HttpServer** (чистая реализация без фреймворков)
- **JUnit 4** (тестирование)
- **Gson** (JSON сериализация)

## 📁 Структура проекта

```
src/
├── adapters/            # JSON адаптеры для сериализации (Duration, LocalDateTime)
├── exceptions/          # Кастомные обработчики ошибок
├── handlers/            # Кастомные HTTP обработчики
├── managers/            # Логика управления задачами (in-memory, file-backed)
├── model/              # Сущности (Task, Epic, Subtask)
└── server/             # Конфигурация сервера
```
